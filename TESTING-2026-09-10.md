## Batas pengujian

- Tes JavaScript memakai respons server simulasi; belum memverifikasi autentikasi Supabase langsung, rendering Vue, tampilan toast native, ataupun double-Back untuk keluar.
- Emulator `emulator-5554` tetap offline setelah reconnect dan restart layanan ADB. APK belum dipasang ulang dan instrumented/UI test belum dijalankan.
- Lint offline gagal karena JAR lint 32.4.0, lint-checks, lint-api, intellij-core, dan kotlin-compiler belum tersedia di cache. Pemeriksaan lint belum dinyatakan lulus.
- Percobaan ulang lint online kembali tertahan pada perhitungan task graph tanpa keluaran lanjutan dan dihentikan; penyebab penundaan online belum dipastikan.
- Percobaan build sebelumnya tertahan dan mengunci configuration cache. Build yang berhasil memakai mode offline dan menonaktifkan configuration cache tanpa mengubah konfigurasi proyek.
- Perubahan implementasi Antigravity dipertahankan; sesi ini menambahkan tes regresi dan laporan saja. APK terdahulu tetap tersedia.

## Langkah pengujian perangkat berikutnya

1. Pulihkan emulator hingga `adb devices` menampilkan status `device`.
2. Pasang APK menggunakan `adb install -r` agar data aplikasi dipertahankan.
3. Uji login kosong, PIN kosong, kredensial salah, dan login benar untuk admin/kader.
4. Uji Kartu Kontrol/KMS, modal SKDN, pengaturan sesuai peran, logout, dan sesi setelah aplikasi dibuka ulang.
5. Uji Back menutup dialog dan kembali melalui layar asal; pada portal/login, dua kali Back dalam dua detik harus keluar.
6. Selesaikan `lintDebug` setelah dependensi lint dapat diunduh.

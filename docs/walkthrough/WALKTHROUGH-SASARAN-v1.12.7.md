# Sasaran bulanan dan Data Balita

Pasang versi 1.12.7 sebagai pembaruan tanpa menghapus penyimpanan aplikasi. Tekan Sinkronkan saat server dapat dijangkau. Angka sasaran di beranda dan daftar pendaftaran mengikuti Sasaran & Impor di web pada periode yang sama.

Riwayat Bulanan dan pilihan Semua Balita tetap dapat membuka master seluruh anak Posyandu. Anak yang baru didaftarkan tersedia di master, tetapi hanya masuk sasaran layanan bulanan setelah ditambahkan admin melalui web. Scan kartu anak yang belum menjadi sasaran menampilkan arahan ini dan tidak membuat check-in.

Pengukuran yang tertunda tetap disimpan lokal. Perbaikan ini tidak menghapus atau mengubah sasaran web.
